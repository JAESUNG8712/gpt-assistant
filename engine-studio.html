이 엔진에 대하여

이 AI는 외부 라이브러리 없이 순수 JavaScript 행렬 연산으로 구현된 트랜스포머입니다.

• 임베딩 → 셀프 어텐션 → 피드포워드 블록 2개
• 역전파(Backpropagation)를 직접 수학 공식으로 구현
• Adam 옵티마이저로 학습
• 대화할수록, 텍스트를 더 많이 학습할수록 향상

처음엔 품질이 낮지만 1000 스텝 이상 학습하면 패턴을 익히기 시작합니다.
