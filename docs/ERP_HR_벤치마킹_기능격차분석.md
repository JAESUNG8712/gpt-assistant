## 2. 모듈별 상세 분석

### 2.1 회계 — 가장 격차가 큰 영역 (벤치마크: 더존, 경리나라, SAP B1)

**보유**: 계정과목, 거래처(첨부·일괄업로드), 전표(차대변 검증, 임시→확정→취소), 세금계산서(사내용), 시산표/월별손익/거래처집계 리포트, ERP 급여 CSV 내보내기

**부재/미흡 (우선순위순)**
1. **매출채권/매입채무(AR/AP) 관리** — 상용 ERP의 핵심. 세금계산서·전표에 거래처는 있으나 수금/지급 등록, 거래처별 미수·미지급 잔액, 채권 연령분석(aging), 수금예정표가 없음. → 더존의 "받을어음/미수금 현황", SAP B1의 Incoming/Outgoing Payments에 해당.
2. **경비정산(법인카드·개인경비 청구)** — 국내 기업 전산화 1순위 수요. 직원이 영수증 첨부해 경비 신청 → 전자결재 연동 → 승인 시 회계 전표 자동 생성 → 급여 합산 또는 개별 지급. 기존 전자결재·급여 인프라가 있어 구현 비용 대비 효과가 가장 큼(스펜딧/비즈플레이 벤치마크).
3. **급여→회계 자동전표** — 급여 확정 시 급여/예수금(4대보험·소득세) 분개 자동 생성. 현재는 CSV 내보내기까지만.
4. **부가세 신고 자료** — 매출/매입 세금계산서 합계표, 기간별 부가세 예수/대급금 집계(홈택스 신고 보조).
5. **고정자산 관리** — 자산 등록·감가상각(정액/정률)·잔존가액. 재고 품목의 `자산번호` 필드가 이미 있어 확장 접점 존재.
6. **예산 통제 연동** — `budget.js` 예산 모듈이 회계와 분리돼 있음. 부서별 예산 대비 집행(전표) 실적 대사가 없음. → 영림원의 예산통제(신청 시 잔액 체크) 벤치마크.

### 2.2 영업 (벤치마크: 영림원, NetSuite, 세일즈포스-lite)

**보유**: 견적→발송→수주→출고/매출(재고 차감+세금계산서 자동발행), 영업 실적 대시보드(목표대비/거래처별/파이프라인)

**부재/미흡**
1. **수금 관리** — 수주·매출 이후 수금 일정/실적 추적이 없어 영업 사이클이 "매출 발생"에서 끊김. AR과 함께 구현하면 됨.
2. **CRM 기초(영업활동 관리)** — 거래처별 접촉 이력(미팅/통화/메일), 영업기회(Lead→Opportunity) 단계 관리, 담당자 배정. 파이프라인 대시보드는 있으나 데이터 입력 단위가 견적서뿐임.
3. **계약 관리** — 계약서 등록(기간·금액·갱신일), 갱신 임박 알림. 유지보수·구독형 매출 기업에 필수.
4. **납품서/거래명세서 출력** — 세금계산서 외에 거래명세서 양식 출력(국내 관행상 필수 서류).
5. **판가/할인 정책** — 품목별 표준판가, 거래처별 단가, 할인율 승인 한도.

### 2.3 구매·재고 (벤치마크: 이카운트, SAP B1)

**보유**: 구매요청(전 직원)→승인→발주 전환, 발주→입고(재고+매입계산서 자동), 품목/창고/재고현황(안전재고 경고)/변동로그/창고이동/수동조정, 전 화면 검색·CSV

**부재/미흡**
1. **부분입고/분할납품** — 현재 발주 전량 일괄 입고만 가능. 미납잔량 관리 필요.
2. **재고실사** — 실사 카운트 시트 입력 → 시스템 재고와 차이 일괄 조정 → 실사 이력. 현재는 단건 수동 조정뿐.
3. **재고자산 평가(원가)** — 품목 표준원가/이동평균 단가가 없어 재고자산 금액·매출원가·마진 계산 불가. 회계 손익 정확도와 직결.
4. **로트/시리얼 추적, 유효기간** — 제조·식품·의료 업종이면 필수, 아니면 후순위.
5. **거래처(공급사) 평가** — 납기준수율·불량률 기반 공급사 등급.

### 2.4 인사 (벤치마크: flex, 자버, SuccessFactors)

**보유**: 인사기록(발령/변동이력), 조직도(직책자 우선 정렬), 증명서 발급(직인), 인사통계, 장기근속·우수사원 포상, 핵심인재/저성과자 관리, 승진 심사, 복지포인트, 법정의무교육, 건강검진

**부재/미흡**
1. **온보딩/오프보딩 체크리스트** — 입사자: 계정발급·장비지급·서약서·교육 등 단계별 체크리스트+담당자 배정, 퇴사자: 자산회수·계정말소·퇴직정산 연동. flex의 대표 기능.
2. **전자 근로계약/연봉계약** — 계약서 템플릿 → 전자서명 → 보관. 연봉조정 이력은 있으므로 계약서 산출물만 붙이면 됨.
3. **인력계획(TO 관리)** — 부서별 정원 대비 현원, 채용 요청과 연동.
4. **직원 셀프서비스 강화** — 본인 인사정보 변경 신청(주소·계좌 등)→승인 흐름(현재 changeRequests 인프라 활용 가능).
5. **조직개편 시뮬레이션** — 발령 예정안을 임시 조직도로 미리보기 후 일괄 발령.

### 2.5 평가·성과 (벤치마크: Workday, 레몬베이스)

**보유**: KPI 목표/실적/1·2차 승인, 등급비율·동점자 처리, 역량/리더십/다면평가, 평가 진행현황, 결과 공개 제어 — **상용 대비 강점 영역**

**추가하면 좋은 것**
1. **상시 피드백/1on1 기록** — 연 단위 평가 사이에 수시 피드백·면담 기록 누적(레몬베이스 벤치마크).
2. **OKR 뷰** — 기존 KPI 데이터를 목표 트리(회사→부서→개인 정렬)로 시각화.
3. **평가 캘리브레이션 회의 지원** — 부서 간 등급 분포 비교 화면(등급비율 데이터 이미 있음).

### 2.6 근태·휴가 (벤치마크: 시프티, flex)

**보유**: GPS 출퇴근(다중 위치), 근무시간/요일/회사휴일, 유연근무 옵션, 연차 관리·사용계획, 주52시간 위젯, 근태 캘린더

**부재/미흡**
1. **초과근무(연장/야간/휴일) 신청·승인** — 신청→결재→수당 자동 반영 흐름. 급여의 연장근로수당 계산과 연결하면 완성도 높음.
2. **교대/스케줄 근무** — 시프트 편성표, 교대조 관리. 교대제 사업장이 아니면 후순위.
3. **자동 알림** — 미출근/미퇴근 처리 알림, 연차 소멸 임박 알림(알림센터 인프라 존재).
4. **휴게시간·외출/복귀 기록** — 근로시간 산정 정밀화.

### 2.7 급여 (벤치마크: 더존 급여, 자버)

**보유**: 급여 계산(과세/비과세, 직책·연구수당 규칙), 명세서, 경조사비/인센티브 조정, 월별/연간 누적, ERP용 CSV

**부재/미흡**
1. **퇴직금/퇴직연금 추계** — 근속·평균임금 기반 퇴직급여 충당금 추계액.
2. **연말정산 보조** — 간소화 자료 업로드→공제 반영은 큰 작업이므로, 최소한 원천징수영수증 출력.
3. **급여대장 은행 이체 파일** — 은행별 대량이체 포맷(CSV) 생성.
4. **급여 마감(lock)** — 특정 월 급여 확정 후 소급 수정 잠금 + 수정 시 차액 정산.

### 2.8 전자결재·그룹웨어 (벤치마크: 다우오피스, 네이버웍스)

**보유**: 기안/상신/결재/수신/참조/완료함, 양식 관리(미리보기), 결재라인 설정, 게시판(권한/익명), 회의실 예약(주간뷰), 알림센터, 캘린더(.ics 내보내기), 웹훅(Slack 등)

**부재/미흡**
1. **결재 위임/부재 설정** — 휴가 중 대결자 지정, 기간 자동 복귀.
2. **전결 규정** — 금액·유형별 전결권자 자동 결정(예: 100만원 이하 팀장 전결). 구매요청·경비정산과 결합 시 효과 큼.
3. **문서함/자료실** — 부서별 파일 저장소, 버전 관리는 후순위.
4. **자원 예약 확장** — 회의실 외 법인차량·장비 예약(기존 회의실 예약 구조 재사용 가능).
5. **모바일 푸시** — PWA 알림(Web Push)로 결재/공지 도달률 개선.

### 2.9 BI·경영정보 (벤치마크: 더존 경영대시보드, NetSuite SuiteAnalytics)

**부재** — 경영진용 통합 대시보드가 없음. 이미 존재하는 데이터(매출/매입/인건비/인원/근태/프로젝트 가동률)를 한 화면에 모은 **경영 현황판**(월 매출·손익 추이, 인원·퇴사율, 부서별 인건비, 미수금 상위 거래처)이 상용 ERP 대비 체감 격차를 가장 빠르게 줄여줌.

### 2.10 시스템·보안 (벤치마크: 공통)

**보유**: 역할 기반 접근제어(PAGE_ROLES), 활동 로그, 데이터 백업/복원, 실시간 동기화(SSE)

**부재/미흡**
1. **비밀번호 정책/2단계 인증** — 최소 길이·주기 변경 강제, TOTP 2FA(관리자 계정만이라도).
2. **개인정보 마스킹·열람 로그** — 주민번호/계좌/연락처 마스킹 표시 + 열람 기록(개인정보보호법 대응).
3. **세션 타임아웃** — 무활동 자동 로그아웃.
4. **데이터 보존/삭제 정책** — 퇴직자 개인정보 보유기간 경과 시 파기 절차.

## 3. 우선순위 로드맵 제안

| 순위 | 기능 | 근거 |
|---|---|---|
| 1 | **경비정산(법인카드/개인경비)** | 전 직원이 매달 쓰는 기능. 전자결재·급여·회계 기존 인프라 재사용으로 투자 대비 효과 최대 |
| 2 | **AR/AP(수금·지급 관리)** | 회계 모듈을 "입력 전용"에서 실무 가능 수준으로 끌어올리는 핵심. 영업 수금관리도 함께 해결 |
| 3 | **급여→회계 자동전표 + 급여 마감** | 이중 입력 제거, 손익 정확도 향상 |
| 4 | **초과근무 신청·승인 → 수당 연동** | 근태-급여 연결 고리 완성, 52시간 관리 실효성 |
| 5 | **경영 대시보드(BI)** | 기존 데이터 재활용만으로 경영진 체감 가치 큼 |
| 6 | **온보딩/오프보딩 체크리스트** | HR SaaS 대비 가장 눈에 띄는 공백 |
| 7 | **부분입고·재고실사·표준원가** | 구매/재고 실무 완성도 |
| 8 | **전결 규정·결재 위임** | 결재 정체 해소, 경비정산과 시너지 |
