🔄 데이터 동기화

OneDrive의 AI-Assistant 폴더를 통해 기기 간 데이터를 공유합니다.

📤 이 기기 → OneDrive

현재 기기의 MiniGPT 가중치와 지식을 OneDrive에 저장합니다

📥 OneDrive → 이 기기

OneDrive의 최신 데이터를 현재 기기에 불러옵니다

💻 PC 서버 동기화

PC에서 서버(npm start)가 실행 중일 때 추가로 PC 데이터도 동기화할 수 있습니다.

ℹ️ Azure 앱 등록 안내 (최초 1회)

1
portal.azure.com 접속 (무료)

Microsoft 계정(OneDrive 계정)으로 로그인합니다.

2
앱 등록 → 새 등록

검색창에 "앱 등록" 검색 → 새 등록 클릭
이름: AI-Assistant
계정 유형: 개인 Microsoft 계정 포함

3
리디렉션 URI 추가

플랫폼: 단일 페이지 애플리케이션(SPA)
URI 추가:

https://jaesung8712.github.io/gpt-assistant/onedrive-sync.html https://jaesung8712.github.io/gpt-assistant/engine-ipad.html http://localhost:3000/onedrive-sync.html
4
클라이언트 ID 복사

앱 개요 페이지의 애플리케이션(클라이언트) ID를 위 입력란에 붙여넣기

5
API 권한 확인

API 권한 → Files.ReadWrite, User.Read 확인
(기본으로 추가되어 있음)
