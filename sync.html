PC ↔ iPad 동기화

동기화 흐름

PC(내부망)와 iPad(외부망)는 직접 연결 없이 파일 교환으로 지식을 공유합니다.

💻 PC (내부망) Ollama + 벡터 지식DB
학습된 내용 내보내기
⇄
📁 파일 전달 iCloud Drive
USB 케이블
이메일 첨부
⇄
📱 iPad (외부망) PocketPal AI
로컬 LLM 실행

STEP 1 PC 지식 내보내기 (PC → iPad)

PC에 축적된 학습 지식을 파일로 내보냅니다. iPad 앱에 가져오면 PC의 지식을 바탕으로 답변합니다.

STEP 2 iPad 앱 설치 및 설정

추천 앱

PocketPal AI
가장 쉬운 설정. 다양한 모델 지원. 채팅 내보내기 가능.
무료 ★ 추천
LLM Farm
오픈소스. GGUF 모델 지원. 시스템 프롬프트 설정 가능.
무료
Private LLM
가장 깔끔한 UI. Metal GPU 가속. 대화 내보내기 지원.
유료

PocketPal AI 설정 순서

1
App Store에서 "PocketPal AI" 검색 후 설치

무료 앱입니다. 첫 실행 시 모델 다운로드를 안내합니다.

2
모델 다운로드 (앱 내부)

Models 탭 → Phi-3.5-mini-instruct (Q4) 또는 Qwen2.5-1.5B 선택 → 다운로드 (1~2GB, Wi-Fi 권장)

3
위 STEP 1에서 다운받은 ipad-system-prompt.txt를 iPad로 전달

방법: iCloud Drive에 저장 → iPad Files 앱에서 열기 / 이메일 첨부 전송

4
PocketPal AI → Settings → System Prompt에 내용 붙여넣기

파일 내용을 전체 복사 → 앱 시스템 프롬프트에 붙여넣기. 이제 PC의 지식을 가지고 답변합니다.

STEP 3 iPad 대화 내용 → PC로 가져오기

iPad에서 나눈 대화를 PC 지식 베이스에 추가합니다.

PocketPal AI 대화 내보내기 방법

1
PocketPal AI → 대화 목록 → 내보내기(Export)

JSON 형식으로 내보내기. Files 앱 → iCloud Drive에 저장 또는 이메일로 PC에 전송

2
PC에서 파일을 받아 아래에 업로드

iCloud for Windows 동기화 / USB 연결 / 이메일 다운로드 후 업로드

📱

iPad 내보내기 파일을 여기에 드래그하거나 클릭하여 선택

지원: PocketPal JSON, LLM Farm JSON, 일반 텍스트

📁 파일 전달 방법 상세

방법 1: iCloud Drive (권장)

1
PC에 iCloud for Windows 설치

Microsoft Store 또는 Apple 공식 사이트에서 다운로드 → Apple ID로 로그인

2
내보낸 파일을 iCloud Drive 폴더에 복사
C:\Users\A1292024032\iCloudDrive\AI-Sync\

iPad Files 앱 → iCloud Drive → AI-Sync 폴더에서 자동으로 보임

방법 2: USB 케이블

1
iPad를 PC에 USB로 연결

Windows 탐색기 → 이 PC → Apple iPad → Files → PocketPal AI 폴더

2
파일 복사/붙여넣기

PC→iPad: ipad-system-prompt.txt 복사
iPad→PC: 대화 내보내기 파일 복사

방법 3: 이메일 / 메시지

내보낸 파일을 자신의 이메일로 발송 → iPad에서 수신 → Files 앱에 저장

파일 크기가 크면 Google Drive / OneDrive에 업로드 후 iPad에서 다운로드

⚙️ 자동 동기화 설정 (iCloud 폴더 감시)

PC 서버가 iCloud Drive 폴더를 감시하다가 iPad 내보내기 파일이 생기면 자동으로 가져옵니다.
