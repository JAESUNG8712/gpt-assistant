← 팀 에이전트 관리로

1. 자료 업로드

① 인원 현황 파일(부서별 월 인원수)을 업로드하면 자동 반영됩니다.
② 판관/용역/경상 상세 파일(부문·팀·항목별 월 금액)을 업로드하면 인원 현황과 자동 연계되어 사업부별 요약에 합산됩니다.
같은 부서/월(또는 부서/팀/항목/구분/월) 데이터를 다시 업로드하면 기존 값이 자동으로 최신 값으로 갱신됩니다(중복 누적 없음).

2. 사업부별 통합 요약

인원 현황(①)과 판관/용역/경상 상세(②)를 부서 기준으로 연계한 합산 결과입니다. ①만 존재 인원만 있고 금액 상세가 없는 달, ②만 존재 금액 상세만 있고 인원 데이터가 없는 달을 표시합니다. 금액은 항목별 고유 키로 갱신되므로 재업로드해도 중복 합산되지 않습니다.

4. 사업계획

기준연도 매출과 성장률·매출원가율·판관비 항목별 가정을 입력하면 다년도 추정 손익·잉여현금흐름과 함께 비율 분석(매출총이익률/영업이익률/순이익률/전년대비 성장률)·손익분기점(BEP) 분석을 자동 계산합니다. 같은 이름의 "시나리오"(낙관/기본/보수 등)를 지정해두면 여러 계획을 체크박스로 선택해 나란히 비교할 수 있습니다.

시나리오 비교

비교하고 싶은 사업계획을 2개 이상 체크한 뒤 버튼을 누르세요. 계획별 기준연도가 달라도 "연차(Y1,Y2...)" 기준으로 비교합니다.
